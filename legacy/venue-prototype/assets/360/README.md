# Eternaluxe 360° bouquet frames

Add 24–36 photographs in clockwise order, named `bouquet-001.webp` through `bouquet-036.webp`. Keep camera, lighting, crop, vase position, and bouquet condition identical in every frame. Use a transparent background and a square 1200–1600 px canvas.

Then add each filename to `manifest.json` in order. The hero automatically switches from its real-photo fallback to the draggable 360° canvas sequence without any code changes.
